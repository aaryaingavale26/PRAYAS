📘 Browser Permissions & Technical Requirements

For the 36-hour hackathon, please keep the following browser requirements in mind:

  • Supported Browsers: Speech recognition relies on the Web Speech API (`SpeechRecognition` or `webkitSpeechRecognition`). Google Chrome, Chromium, and Microsoft Edge provide full out-of-the-box support. Firefox requires custom flag configuration.
  • Microphone Permissions: The browser will prompt for microphone permission on the first activation. If denied, Chrome marks it as not-allowed. Reset permissions by clicking the padlock or tune icon in the Chrome URL bar.
  • Secure Context Requirement: Web Speech API strictly requires a secure context (either https:// or http://localhost / http://127.0.0.1). It will fail with permission errors on raw file:// URLs in some Chromium versions.
  • Speech Recognition Network Dependency: Chromium's Web Speech API implementation streams audio to Google's cloud speech recognizer. An active internet connection is required for transcription.
  • No Auto-Continuous Listening: To comply with WCAG 2.1 AA and privacy best practices, listening must be explicitly triggered by the user (via button click or keyboard shortcut) rather than listening endlessly.
